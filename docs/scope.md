- [ ] Price comparison UI

- [ ] Native iOS/Android UI

## What we are not building

Do not burn hackathon time on:

- a general AI shopping chatbot
- autonomous agents
- a custom computer-vision model
- a custom virtual try-on model
- complicated user accounts
- social network features
- full checkout
- payment processing
- retailer inventory synchronization
- a web app or PWA
- large recommendation engines
- advanced personalization
- unnecessary microservices

A polished native app is enough.
